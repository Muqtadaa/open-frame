# Audit · 2026-10-02, as verified and acted on

The external audit of 2026-10-02 ordered the work as: protect irreversible
operations; harden the security boundaries; make the documentation true; make
maintenance mechanical; then reset the product. Each finding was checked
against main before anything was changed, so a finding that no longer held was
not "fixed" twice. This is the current-state record; the earlier reviews in
this folder are frozen.

## Closed

All merged into `Muqtadaa/open-frame`.

### Security gaps still standing

The decisions and their reasons are in the Known gaps table of
[11-security.md](../architecture/11-security.md#known-gaps). By name:

- **Revisit:** a board's whole state must fit in one 32 MiB message to publish
  it, and what changed offline in one to resync; the owner key and token travel in the WebSocket URL.
- **Accepted:** the room relays and persists any decodable editor update (ADR
  0016); viewers' awareness is relayed and any peer may publish state for any
  client id (for now); unclaimed legacy rooms admit anyone as an editor; a
  pre-owner-key board's owner key goes to whoever adopts first; `claim` is
  unauthenticated; password rationing is per board, so a guesser makes other
  link holders wait; MCP cannot open password-protected boards; the page's
  policy allows inline styles; `CodeView` trusts highlight.js to escape.
